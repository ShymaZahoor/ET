Edge Gateway — Raspberry Pi 4
DeviceRaspberry Pi 4 (4GB RAM)
RoleEdge AI Inference + MQTT Broker
ML ModelIsolation Forest (edge_runner.py)
MQTTMosquitto @ localhost:1883
Status● Simulated Online

The Raspberry Pi 4 acts as the edge computing hub. It runs the Isolation Forest model locally (edge/edge_runner.py), detects anomalies before data reaches the cloud, and caches telemetry offline when connectivity drops. Data is forwarded to the Flask backend via REST or MQTT.
